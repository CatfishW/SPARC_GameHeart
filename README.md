# Game Heart: Rhythm of Life

A remastered, standalone Unity 6 (6000.5.10f1, URP, WebGL) version of **Game Heart** from the
SPARC project (`~/Development/Yanlai_Zlad_SPARC_Merge/Assets/GameHeart`). It keeps the original
lessons, Captain B and the scenarios (cold → faster, exercise → faster, sickness → faster,
sleep → slower) but replaces the CyanStars-based prototype with a new rhythm engine, stage,
cutscenes, UI, soundtrack and voice-over.

Live: https://ping.agaii.org/game/gameheart/

## Getting started (fresh clone)

Media (songs, voice, art, fonts, models) is stored with **Git LFS**, so install it before cloning:

```bash
git lfs install
git clone git@github.com:CatfishW/SPARC_GameHeart.git
cd SPARC_GameHeart
git lfs pull                      # only needed if the clone skipped LFS objects
```

1. Open the folder with **Unity 6000.5.10f1** (Unity Hub → Add project from disk). All packages
   (URP 17.5, uGUI/TextMesh Pro) ship with that editor, so no package download is needed. The first
   import builds `Library/` and takes a few minutes. `Assets/Scenes/Main.unity` is the only scene;
   press Play and everything is built at runtime by `GameRoot`.
2. WebGL build (needs the editor's WebGL module):
   `Unity -batchmode -quit -projectPath . -executeMethod GameHeartEditor.GameHeartBuilder.BuildWebGL`
   → `Builds/WebGL`. Serve it with `python3 Tools/qa/serve.py --dir Builds/WebGL --port 18790`.
3. Optional tooling:
   - Browser QA: `cd Tools/qa && npm install` (puppeteer-core) and Google Chrome
     (set `CHROME_PATH` if it is not in `/Applications`).
   - Content pipeline: Python 3.12 with `pip install -r Tools/requirements.txt`; FFmpeg for MP3 export.
   - `Tools/compile-check.sh` is a 1-second out-of-editor compile check (macOS editor path).

What is deliberately **not** in the repo (regenerable or superseded): `Library/`, `Builds/`, QA
screenshots, unchosen song/art takes, mastered WAV duplicates and the superseded Audio8 voice set.
The repo keeps the 14 chosen song takes (`Tools/music/raw`), Whisper word-timing caches
(`Tools/music/work`), the Qwen3 raw voice takes and the picked source art, so `build_music.py`,
`master_voice.py` and `pack_art.py` can be re-run without the generation servers.

## What is in the game

| Chapter | Song (BPM) | Lesson |
|---|---|---|
| Prologue | — | Shrink down, reach the heartbeat control center |
| 1 First Beat (tutorial) | First Beat (109) | Taps, holds, heartbeat pulses; what the heart does |
| 2 Cold Snap | Frostbite Pulse (124) | Cold → beat faster to keep the core warm |
| 3 Full Sprint | Sprint Circuit (150) | Exercise → faster, more oxygen to muscles |
| 4 Fever Front | Fever Front (140) | Sickness → faster, rush white blood cells |
| 5 Night Tide | Night Tide (71) | Sleep → slower, rest and repair |
| 6 Finale | Symphony of the Heart (130) | Recap, ending, credits |

Each chapter: title card → voiced intro cutscene → "How should the heart respond?" decision
(wrong answers play a consequence scene and let you choose again) → song card (Easy/Normal/Hard,
note speed) → rhythm stage → results (Heart Stability ≥ 70% = vitals stable) → win or struggle
cutscene → Pulse Check quiz. Cleared chapters unlock free play from the Heartbeat Control Center.

Controls: **D F J K** (or arrows / Z X N M) for the four lanes, **Space** or any lane for full-width
heartbeat pulses, **Esc** to pause. Touch: tap the lanes. Settings include volumes, note speed,
audio offset with tap calibration, auto-advance, lyrics, reduced flashing and graphics quality.

## Layout

- `Assets/Scripts/Core` — `GameRoot` (builds everything at runtime), `GameFlow` (the whole game as one
  coroutine + QA jumps), `AudioDirector`, `Content` (story/charts/art streaming), save + settings.
- `Assets/Scripts/Rhythm` — `RhythmGame` (clock, input, judging, scoring, autoplay) and `HighwayView`.
- `Assets/Scripts/Stage` — `StageWorld` (painted backdrop, beat tunnel, holographic heart, blood cells,
  themed particles, URP post-processing, camera) and procedural meshes/textures.
- `Assets/Scripts/UI` — uGUI/TMP screens built in code: title, hub, cutscene, decision, quiz, song card,
  HUD, pause, results, settings (+ calibration), credits, overlay (fades, loading, chapter cards).
- `Assets/Resources/Shaders` — custom URP shaders (tunnel, highway, notes, hologram, cells, backdrop, UI glow).
- `Assets/Resources/{Data,Charts,Voice,Audio,Portraits,Fonts,Models}` — generated content.
- `Assets/StreamingAssets/{Music,Art}` — MP3 songs/BGM and JPG stills, streamed on demand.
- `Assets/Editor/GameHeartBuilder.cs` — project setup + WebGL builds.

## Content pipeline (Tools/)

All content is regenerated by scripts; `$PY` below is a Python 3.12 environment with
`Tools/requirements.txt` installed. The generation servers (YuE2, Qwen3-TTS, Qwen-Image) are the
original team's private machines; the scripts document exactly how each asset was made.

| Step | Command |
|---|---|
| Story text → `story.json` + voice line list | `python3 Tools/story/build_story.py` |
| Songs (YuE2 on benwulab via tang-server tunnel :28190) | `python3 Tools/music/yue_queue.py [keys]` |
| Score takes (tempo, Whisper lyric match) | `$PY Tools/music/score_takes.py` |
| Master + game-size edits + charts | `$PY Tools/music/build_music.py [keys]` |
| Captain B voice (Qwen3-TTS 1.7B CustomVoice on benwulab GPU 1) | `python3 Tools/voice/tts_batch.py --speaker Ryan` then `$PY Tools/voice/master_voice.py --raw-dir Tools/voice/qwen3/raw --out-dir Tools/voice/qwen3/mastered --provider Qwen3-TTS-12Hz-1.7B-CustomVoice --secondary-asr Tools/voice/qwen3/independent-asr.json` |
| SFX synthesis | `$PY Tools/sfx/make_sfx.py` |
| Art (Qwen-Image on chongyou GPU 1; gpt-image-2.5) | `Tools/art/jobs.py`, `qwen_task.py`, `gpt_image.py`, then `$PY Tools/art/pack_art.py` |
| Fonts (OFL: Orbitron, Rajdhani, Inter) | `Tools/fonts/` |

gpt-image-2.5 reads its key from `~/.config/gameheart/subtoken.env` (never committed or shipped).

## Voice replacement and quality checks

The voice pipeline uses the existing cached Qwen3-TTS 1.7B CustomVoice model and Python environment
on `benwulab-remote`; it generates static WAV assets, so players do not make TTS API requests.
`tts_batch.py --audition` compares Ryan and Aiden on three representative lines. The full render
keeps one speaker identity and applies restrained direction for the seven existing scene moods.
Generation resumes only when both the request signature and audio SHA-256 match.
Approved per-line seeds are retained in the renderer. One singular/plural recognition ambiguity
was checked with an independent, unprompted Whisper medium.en model. The evidence is tied to
the raw clip SHA-256; both decoder transcripts remain in the mastering report. If a regenerated
clip changes, refresh that independent check rather than reusing stale evidence.

Raw audio and generation provenance live in `Tools/voice/qwen3/raw`. Mastering writes to
`Tools/voice/qwen3/mastered`; review its speech-recognition and waveform QA report before copying
the 55 WAVs into `Assets/Resources/Voice` and `voice.json` into `Assets/Resources/Data`.
Preserve the existing `.meta` files and rebuild WebGL: the clips are embedded Unity resources.
The superseded Audio8 voice set is not in the repo (it was backed up locally as
`Tools/voice/backups/audio8-20261104`). The old `pick_takes.py` is a legacy Audio8 tool and is not
part of the Qwen3 pipeline. Voice import uses Vorbis quality 0.8.

## Build, test, deploy

```bash
Tools/compile-check.sh                    # ~1 s out-of-editor C# compile
/Applications/Unity/Hub/Editor/6000.5.10f1/Unity.app/Contents/MacOS/Unity -batchmode -quit -projectPath "$PWD" \
  -executeMethod GameHeartEditor.GameHeartBuilder.BuildWebGL -logFile Logs/build.log   # -> Builds/WebGL
python3 Tools/qa/serve.py --dir Builds/WebGL --port 18790 &      # then: cd Tools/qa && npm install (once)
node Tools/qa/drive.mjs "qa=1&fast=1&auto=1&jump=cold:song&diff=hard" cold/hard --until=song_end --every=8000
```

QA query flags: `qa=1` (skip start gate, enable hooks), `fast=1` (fast cutscenes), `auto=1` (autoplay
bot), `jump=title|hub|prologue|credits|<chapter>[:card|intro|decision|song|results|win|struggle|quiz|free]`,
`diff=easy|normal|hard`, `seek=<sec>`, `choose=faster|same|slower`, `quiz=right|wrong`, `unlock=1`,
`fresh=1`, `nosave=1`. The game logs `GH_EVENT <name> <detail>` to the console for the driver.

Deploy: `python3 Tools/deploy/stage.py` makes `Builds/stage`, then rsync to tang-server and the
sudo copy into `/www/wwwroot/ping.agaii.org/game/gameheart/` (see Tools/deploy/README).
